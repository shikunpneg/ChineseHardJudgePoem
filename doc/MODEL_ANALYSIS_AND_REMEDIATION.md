# 顾城 MiniMind 三模型对比分析与补救方案

> 日期：2026-08-18
> 范围：AR（Softmax Attention 自回归）、dLM（扩散语言模型）、Linear（Gated DeltaNet 线性注意力）
> 结论先行：**AR 最优的根本原因是其"逐 token 条件生成 + 训练/推理目标一致"的本性，天然契合小数据小模型场景；dLM 与 Linear 的劣势均可归因到训练/推理 gap 与参数未充分训练，且都可通过 warm-start + 数据/调参补救。**

---

## 1. 现状与观测数据

| 模型 | 机制 | 迁移初始化 | 数据 | 生成合格率 | 平均长度 | 典型故障 |
|---|---|---|---|---|---|---|
| AR (full_sft) | Softmax 因果自回归 | AR 权重 | pretrain 7481 + SFT 213 | **100%** | ~90 字 | 无 |
| dLM | 双向注意力 + A2D + MDM 迭代去噪 | AR 权重（A2D） | pretrain 7481（5 epochs） | 100%（但需过滤 94% 无效样本） | ~43 字 | 输出过短、`</think>`/`我不`句式重复 |
| Linear | Gated DeltaNet（6/8 层线性）+ ShortConv | AR 权重（A2L，线性层随机初始化） | SFT 213（5 epochs, batch=4） | **0%（100% 乱码 \ufffd）** | - | 预测头未收敛，采样即乱码 |

关键观测：
- dLM 生成 100 个合格样本实际尝试 1814 次（过滤率 94%），说明模型并非"不会"，而是**概率质量分散、确定性不足**。
- Linear 在采样与 greedy 下均 100% 输出 `\ufffd`，是**语言结构完全没有学进去**的典型表现（见 2.3）。

---

## 2. 根因分析

### 2.1 为什么 AR 最优（基准机制）

1. **训练/推理目标一致**：AR 训练与生成都是"给定前缀预测下一个 token"，一步到位，无 gap。104M 小模型不需要处理额外的分布迁移。
2. **自回归 = 条件生成**：每步都能看到前面所有真实生成 token，长程一致性天然有保障（90 字仍通顺）。
3. **数据需求低**：下一 token 预测的监督信号稠密（每个 token 都是训练点），7481 条数据即可学到语言形状。

### 2.2 dLM 差于 AR 的原因

1. **训练与推理目标不一致（主因）**：dLM 训练时用 A2D 对部分 token 加噪为 mask，只对 masked 位置计算加权 CE；推理时却是 MDM 迭代去噪（Gumbel argmax + top-k，24 步逐步 unmask）。两个过程只在"预测 masked token"这一点上相交，但训练是单步、推理是多步自洽 —— 104M 模型拟合不了这个 gap，导致生成置信度低、需要大量重采样。
2. **并行预测缺失长程约束**：迭代去噪的每一步都是**整块并行**预测（block_size=32、24 步），块内 token 彼此独立采样，不像 AR 逐 token 条件生成。这直接导致：生成偏短（平均 43 vs 90 字）、长程衔接弱、句内易卡在固定模板（`</think>`、`我不` 的高频出现就是概率坍缩到局部模式）。
3. **去噪步数与温度不匹配**：默认 steps=24、block_size=32 对小文本过粗；温度 0.7 + Gumbel 噪声在低置信区反复抖动，重复惩罚机制（AR 有 repetition_penalty=1.1）在 dLM 采样里没有等效物，重复无法抑制。
4. **数据量敏感**：扩散语言模型在 7481 条小语料上难收敛（MiniMind 作者原帖也明言"当前效果仍属初级"）。

### 2.3 Linear 100% 乱码的原因

1. **线性注意力层从零随机初始化 + 训练量严重不足（主因）**：A2L 迁移时 6/8 层注意力被替换为 Gated DeltaNet，这些层的 q/k/v/o 投影随机初始化。虽然 embedding/lm_head 复用 AR，但**信息必须穿过随机线性层**才能到达输出头。5 epochs × 213 条数据，batch=4（OOM 被迫调小）→ 有效训练步数极少，线性层远未收敛，语言信号到不了 lm_head。
2. **PyTorch fallback 的双重惩罚**：无 FLA/causal-conv1d 时线性注意力走逐 token 递推，训练极慢且数值路径不同；batch 只能 4，吞吐进一步打折。
3. **输出头依赖深层随机路径**：乱码 `\ufffd` 表明采样最高概率 token 是未登录/无效 token —— 即 lm_head 输出的分布仍是"未训练"的形状，模型实际退化为随机预测。

### 2.4 共同点总结

| 根因维度 | dLM | Linear |
|---|---|---|
| 训练/推理 gap | 高（扩散 vs 去噪） | 无 gap 但模型未收敛 |
| 参数充分训练 | 部分（attention 迁移，FFN 冻结） | 差（6/8 层随机起步） |
| 有效训练量 | 7481×5 | 213×5 / batch4 |
| 采样稳定性 | 需 18 次过滤得 1 合格 | 0 合格 |

→ 一句话：**AR 赢在机制一致且参数充分训练；dLM 赢面在机制但缺校准与步数；Linear 连"学进去"都没做到。**

## 3. 补救方案

### 3.1 dLM 补救（三档递进）

| 档位 | 动作 | 预期收益 | 成本 |
|---|---|---|---|
| D1 采样调优（零训练） | steps 24→64、block_size 32→64、温度 0.7→0.5、top_k 50→30；引入 repetition_penalty（对已 unmask token 降权）；开启 CFG（cfg_scale 0.3~1.0） | 合格率↑、长度↑、重复↓ | 5 分钟改参数 |
| D2 训练校准（低成本） | 用 AR 生成的 100 合格样本 + 顾城真诗构造"CoT→诗"对，做 **dLM-SFT 续训**（epochs 3-5，lr 5e-5），冻结 FFN 只训 attention | 拟合"去噪产出完整诗歌"的目标 | 1 次训练 |
| D3 数据扩充（治本） | pretrain 数据 7481→8 万+（合并顾城全集 OCR 段、海子/张枣/李白诗集、poementer_real 2000 首），先 AR pretrain 再 A2D 迁移 dLM | 从根上解决小数据难收敛 | 需 E 盘空间 ~3GB |

### 3.2 Linear 补救（两档）

| 档位 | 动作 | 预期收益 | 成本 |
|---|---|---|---|
| L1 训练补救 | ① 从 pretrain（而非 full_sft）权重 A2L 迁移；② 线性层 warm-start：将 AR 的 q/k/v/o 权重映射初始化 Gated DeltaNet（随机替换→继承）；③ 训练数据换成 pretrain 7481（而非仅 213 SFT）；④ epochs 5→10；⑤ 若仍 OOM，只替换 4 层线性（full_attention_interval 调大） | 语言结构可学，消灭 \ufffd | 1-2 次训练 |
| L2 环境补救 | 安装 `flash-linear-attention` + `causal-conv1d`（需 GPU + CUDA 编译），batch 4→16，chunk 化训练提速 | 训练吞吐↑、数值稳定↑ | 环境配置，若 GPU 不支持则跳过 |

### 3.3 评估门槛（统一验收）

补救后每模型生成 100 样本（同 20 题目轮换），满足：
- 合格率 ≥ 80%（长度 20~500、无乱码、无英文数字、无 JSON 痕迹、重复率 < 0.3）
- 平均长度 ≥ 60 字
- 与 AR 样本做风格相似度对比（Jaccard/embedding 相似度 ≥ AR 的 80%）

---

## 5. 结论

1. **AR 保持为顾城诗歌主生成器**，后续叠加 CoT（任务 2）。
2. **dLM 走 D1→D2**（采样调优 + CoT 数据校准训练），低成本先试。
3. **Linear 走 L1**（warm-start + pretrain 数据 + 更多 epochs），作为线性注意力研究对照的完整版。
4. 三项补救与 CoT/余华任务共享数据资产（数据集扩充对三模型都有益）。
