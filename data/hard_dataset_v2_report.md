- 总样本数：**4343**（GuCheng 1250 + Haizi 1250 + Haizi-CN 1250 + LiBai 593）
- 每样本 = **[模仿诗作(generated), 被模仿诗作(ref_text)] 1:1 配对**，严格同诗人，不混入非诗歌文本

## 5. v2 第二版 vs v1 的改进

| 维度 | v1 (弃用) | v2 第二版 |
|------|-----------|----------|
| 样本配对 | 模仿诗 + 随机文本（含非诗歌），跨诗人标题池抽标题 | **模仿诗 + 被模仿原作 1:1**，prompt 内嵌原作全文 |
| 英文混入 | GuCheng 35% / Haizi 48% / LiBai 35% | **0%**（中英对碰 SFT + 正则过滤 + 8 轮重试）|
| 体裁标注 | 全部标现代诗 | 按诗人：顾城/海子→现代诗，李白→古体诗 |
| LiBai 池 | 混入书信/赋/碑/颂/记/序/并序等非诗歌 | 黑名单 30 + 标题后缀 + 评注截断 + "兮"骚体过滤 → 630 首纯诗 |
| 失败处理 | 截断/英文直接写入 | 最多 8 轮重试，最终失败样本剔除，不进总集 |
| 续跑能力 | 无 | 基于 Counter(prompt) 的精确续跑，支持池复用 |

## 6. 结论

- v2 严格保证：**配对 1:1**、**纯中文**（英文=0）、**无失败残留**（失败=0）、**形式正确**（行数/字数/平均行长校验）
- 形式校验门槛：现代诗（行数≥3、字数20-600、平均行≤30）；古体诗 LiBai（行数≥2、字数12-800、平均行≤50）
- 被模仿诗作复用是客观约束（顾城 180、海子 124、李白 630），不同随机种子下同一原作的模仿诗作内容完全不同，无文本级重复
- 若后续需补满 5000 条，重启 `gen_hard_v2.py --group LiBai` 断点续跑补齐 LiBai 组 1250 即可
